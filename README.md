# jblog

개인 포트폴리오 겸 기술 블로그.

- 프론트엔드: Next.js (App Router) · Tailwind CSS
- 백엔드: NestJS · Prisma · PostgreSQL
- 개발 방식: Claude Code 에이전트 팀 구현 + Codex 독립 검수
