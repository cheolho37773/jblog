# M1-03 검수 r2

## 종합 판정

수정 후 통과 — 이전 지적의 주요 수정은 반영됐으나, `Button asChild`의 이벤트 합성이 클릭·키보드 이벤트에만 적용되어 일부 자식 핸들러가 여전히 유실된다.

## 지적 사항

### 1. [중간] asChild에서 클릭·키보드 외 이벤트는 자식 핸들러를 덮어쓴다

- 위치: `frontend/src/components/ui/Button.tsx:68`
- 근거: `docs/work/M1/tasks/M1-03.md`의 「오케스트레이터 결정: Codex r1 대응 기준」 #1은 부모에 준 이벤트를 자식과 합성하도록 요구한다. 구현은 `onClick`·`onKeyDown`만 합성하고 나머지는 `passThrough`로 `cloneElement`에 전달하므로, 같은 이름의 자식 이벤트를 덮어쓴다.
- 영향: 부모와 자식 링크에 각각 `onFocus`를 지정한 메모리 내 재현에서 부모 핸들러만 호출됐다. 자식 링크가 포커스·포인터 이벤트로 수행하는 동작이 사라질 수 있다. 현재 합성 테스트는 클릭 이벤트 중심이라 이 경우를 검출하지 못한다.
- 권고: 지원하는 이벤트 속성 전반에 부모·자식 핸들러 합성을 적용하고, `onFocus` 등 클릭 외 이벤트도 양쪽 핸들러가 호출되는지 회귀 테스트를 추가한다.
