# M1-03 검수 r1

## 종합 판정

수정 후 통과 — `Button asChild`의 속성 유실, 터치 타겟 미달, 검증 페이지의 상태 누락과 실행되지 않는 회귀 테스트를 수정해야 한다.

## 지적 사항

### 1. [중간] Button asChild에서 disabled·이벤트·접근성 속성이 유실된다

- 위치: `frontend/src/components/ui/Button.tsx:38`
- 근거: 작업 지시서 `docs/work/M1/tasks/M1-03.md` 동작 규약 3·5와 필수 검증은 링크 합성, disabled 동작, 아이콘 버튼의 접근 가능한 이름을 요구한다. `asChild` 분기는 자식에 `className`만 전달하고 나머지 속성을 버린다.
- 영향: 메모리 내 렌더링으로 확인한 결과, `<Button asChild disabled aria-label="…" onClick={…}>`의 링크에는 해당 속성이 모두 없었다. 비활성 링크가 계속 이동하며, Button에 지정한 이벤트가 실행되지 않고 아이콘 링크의 이름도 누락된다. 기존 테스트는 일반 버튼의 disabled와 링크의 클래스만 각각 검사한다.
- 권고: 자식과 부모의 속성·이벤트를 합성하고 링크의 비활성 동작을 명시적으로 처리한다. `asChild`에서 이벤트·이름 전달과 disabled의 마우스·키보드 동작을 검증한다.

### 2. [중간] 검색 입력과 Badge 링크의 터치 타겟이 44px에 미달한다

- 위치: `frontend/src/components/ui/SearchInput.tsx:21`, `frontend/src/components/ui/Badge.tsx:13`
- 근거: 작업 지시서 동작 규약 5와 `docs/ui_design/ui_design_spec.md` §4.2는 최소 44×44px 터치 타겟을 요구한다. 검색 입력은 줄 높이 20px에 상하 padding 8px로 높이 36px이며, Badge 링크는 md 28px·lg 32px다. 별도 히트 영역 확장이 없다.
- 영향: 모바일에서 해당 입력과 링크의 누를 수 있는 영역이 요구 크기보다 작다. 현재 E2E는 가로 스크롤과 포커스만 검사해 이를 발견하지 못한다.
- 권고: 시각적 크기를 유지하면서 실제 히트 영역을 확장하거나 최소 크기를 적용한다. 모바일에서 실제 입력·클릭 영역을 검증한다.

### 3. [중간] 검증 페이지에 필수 상태와 이미지 Avatar 예제가 누락됐다

- 위치: `frontend/src/app/dev/components/page.dev.tsx:109`
- 근거: 작업 지시서 동작 규약 4와 `docs/work/M1/plan.md` §4는 각 Atom의 variant·크기·hover·focus·disabled 상태를 나열하도록 한다. 페이지에는 고정 hover 예제가 없고, Button의 고정 focus는 primary에만, disabled는 primary·outline에만 있다. SearchInput의 disabled와 Avatar의 이미지 표시 예제도 없다.
- 영향: 후속 디자인 검수에서 누락된 상태와 이미지 표시 경로를 이 페이지로 확인할 수 없다. 섹션 존재 여부를 검사하는 현재 E2E는 예제 누락을 통과시킨다.
- 권고: 적용 가능한 variant·상태 조합과 이미지 Avatar 예제를 추가하고, 필요한 예제의 존재를 테스트로 확인한다. hover 스타일이 기본과 같더라도 비교용 고정 예제를 표시한다.

### 4. [중간] cn의 타이포·색상 병합 회귀 테스트가 실행 대상에서 제외된다

- 위치: `frontend/src/lib/cn.unit.test.ts:1`
- 근거: 작업 지시서의 토큰 교체 검증과 `docs/plan/05_collaboration_architecture.md` §10은 회귀 검증 완료를 요구한다. 그러나 `frontend/vitest.config.mts:17`은 `*.spec.ts`·`*.spec.tsx`만 포함하므로 새 `cn.unit.test.ts`는 실행되지 않는다.
- 영향: 타이포와 색상 유틸이 서로 지워지지 않는지 확인하는 테스트 6건이 `pnpm test`·`pnpm verify`에서 빠진다. 실제 include 패턴으로 파일을 열거한 결과에도 이 파일은 없고 `cn.spec.ts`만 포함됐다.
- 권고: 해당 검증을 기존 `cn.spec.ts`로 옮기거나 지원되는 테스트 파일명으로 변경하고, 테스트 수집·실행을 확인한다.
