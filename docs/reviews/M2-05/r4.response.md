**캡션 위치 일괄 점검표 (오케스트레이터 확정)**

| 위치 | 규칙 |
|---|---|
| 문단(최상위·목록·인용·콜아웃 안) | figure 블록으로 분리(r1~r3 규칙) |
| 링크·참조 링크·강조·굵게·취소선 안(중첩 포함) | 경계에서 나누고 서식·목적지를 복제(r3 규칙) |
| **표 셀** | **셀 안에서** 같은 규칙으로 분리한다. 셀 안에 `figure`를 둔다. 표 구조(행·열 수)는 그대로다 |
| 헤딩(h1~h6) 안 | 블록을 둘 수 없으므로 figure를 만들지 않는다. 캡션은 img `title`로 보존한다. TOC·id에는 영향을 주지 않는다 |
| 각주 정의 등 문법 확정 밖 | sanitize가 요소를 걷는 기존 동작을 유지한다 |
