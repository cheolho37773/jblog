# M2-05 검수 r3

## 종합 판정

수정 후 통과 — 일반적인 링크·강조 내부 이미지의 캡션 변환은 수정되었으나, 일부 링크 내부에서는 캡션 표시 계약을 충족하지 못한다. 중간 심각도 1건의 수정과 회귀 테스트 보완이 필요하다.

## 지적 사항

### 1. [중간] 글자·강조가 섞인 링크 내부 이미지에는 캡션이 표시되지 않는다

- 위치: `frontend/src/lib/markdown/remark-image-caption.ts:60`, `frontend/src/lib/markdown/markdown.spec.tsx:421`
- 근거: `docs/work/M2/tasks/M2-05.md`의 「문법 확정」은 제목 속성이 있는 이미지를 `figure/figcaption`으로 출력하도록 정한다. 현재 구현은 링크의 유일한 직계 자식이 캡션 이미지일 때만 변환한다. 새 테스트는 글자가 섞이면 `figure`가 없어야 한다고 기대하여 계약과 다른 동작을 고정한다.
- 영향: `[글자 ![alt](/uploads/a.png "캡션")](/blog/x)`와 `[**![alt](/uploads/a.png "캡션")**](/blog/x)` 모두 실제 렌더링에서 `figure/figcaption`이 생성되지 않는다. 캡션은 `img title`에만 남아 본문에 표시되지 않으며, 터치 환경에서는 확인하기도 어렵다.
- 권고: 링크 내부를 재귀적으로 처리하고, 목적지·주변 글자·강조 서식을 보존하면서 캡션 이미지를 유효한 `figure/figcaption` 구조로 분리한다. 두 재현 사례에서 보이는 캡션과 링크 목적지 보존을 검증하도록 테스트를 보완한다.
