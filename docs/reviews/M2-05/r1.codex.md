# M2-05 검수 r1

## 종합 판정

수정 후 통과 — 렌더링 예외와 문법·링크 계약 불일치 등 중간 심각도 3건을 확인했다. 아래 항목을 수정하고 재현 테스트를 추가해야 한다.

## 지적 사항

### 1. [중간] 미등록 콜아웃 `constructor`가 본문 렌더링을 실패시킨다
- 위치: `frontend/src/lib/markdown/remark-callout.ts:21`
- 근거: `docs/work/M2/tasks/M2-05.md`의 「문법 확정」은 모르는 종류를 일반 인용문으로 유지하도록 정한다. 그러나 `in` 연산자는 상속된 `constructor` 속성도 허용한다.
- 영향: `> [!constructor]` 다음 줄에 `> 본문`을 입력하면 종류 이름으로 함수가 들어가고, 후속 처리에서 `child.value.trim is not a function` 예외가 발생한다. `renderMarkdown()` 호출 실패를 재현했다.
- 권고: `Object.hasOwn()` 또는 명시적인 허용 목록으로 종류를 검사한다. `constructor`도 일반 인용문으로 렌더되는지 회귀 테스트를 추가한다.

### 2. [중간] 문장 속 이미지의 캡션이 사라진다
- 위치: `frontend/src/lib/markdown/remark-image-caption.ts:13`
- 근거: `docs/work/M2/tasks/M2-05.md`의 「문법 확정」은 `![alt](url "캡션")`에 제목 속성이 있으면 `figure/figcaption`으로 출력하도록 정한다. 이미지가 문단의 유일한 요소여야 한다는 제한은 없다.
- 영향: `앞 ![alt](/uploads/a.png "캡션") 뒤`는 이미지와 앞뒤 글자만 출력된다. `figure/figcaption`이 생성되지 않고 sanitize 단계에서 `title`도 제거되어 캡션을 읽을 수 없다.
- 권고: 앞뒤 본문을 보존하면서 캡션 이미지를 별도 블록으로 변환한다. 문장 속 이미지와 한 문단에 여러 이미지가 있는 경우를 테스트한다.

### 3. [중간] 동일 오리진의 절대 URL도 외부 링크로 처리한다
- 위치: `frontend/src/lib/markdown/MdLink.tsx:5`
- 근거: `docs/work/M2/tasks/M2-05.md`의 「동작 규약」 5는 다른 오리진만 외부 링크로 정의하고 내부 링크는 그대로 유지하도록 정한다. 현재 정규식은 오리진 비교 없이 모든 HTTP(S) 절대 URL을 외부로 판정한다.
- 영향: 사이트 오리진이 `https://jblog.example`일 때 `[내부](https://jblog.example/blog/a)`도 `target="_blank"`로 출력된다. 동일 사이트 글 주소를 붙여 넣으면 의도와 달리 새 탭이 열린다.
- 권고: 사이트 오리진을 기준으로 URL을 해석해 비교한다. 동일 오리진 절대 URL·프로토콜 상대 URL·다른 오리진 URL을 구분하는 테스트를 추가한다.
