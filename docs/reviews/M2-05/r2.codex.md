## 지적 사항

### 1. [중간] 링크·강조 안의 이미지 캡션이 누락된다

- 위치: `frontend/src/lib/markdown/remark-image-caption.ts:57`
- 근거: `docs/work/M2/tasks/M2-05.md`의 「문법 확정」은 `![alt](url "캡션")`에 제목 속성이 있으면 `figure/figcaption`으로 출력하도록 정한다. 현재 처리는 문단의 직계 이미지 자식만 검사하므로 링크·강조 내부 이미지는 변환하지 않는다. 이후 `sanitize-schema.ts`에서 이미지의 `title`도 제거한다.
- 영향: `[![alt](/uploads/a.png "캡션")](https://example.com)` 또는 `**![alt](/uploads/a.png "캡션")**`를 렌더하면 이미지만 남고 `figure`, `figcaption`, 캡션 문자열이 모두 사라진다. 실제 파이프라인과 React 정적 렌더링으로 두 경우를 재현했다.
- 권고: 링크·강조 내부 이미지도 캡션 변환 대상으로 처리한다. 이미지 링크의 목적지와 주변 본문·서식을 보존하면서 유효한 블록 구조로 출력하고, 두 사례의 회귀 테스트를 추가한다.
