# M0-05 검수 r1

## 종합 판정

수정 후 통과 — 루트 Turbo 실행에서 필수 환경변수가 전달되지 않는 문제 1건을 확인했다. 환경변수 검증·분리, 테마 하이드레이션 처리, 폰트·토큰 골격은 지시서에 부합한다.

## 지적 사항

### 1. [중간] Turbo 환경변수 허용 목록 누락으로 루트 빌드가 실패함
- 위치: `frontend/next.config.ts:8`, `frontend/package.json:7` (연관 설정: `turbo.json:4`)
- 근거: `docs/work/M0/tasks/M0-05.md` 동작 규약 1은 frontend 빌드를 루트 `pnpm build`에 포함하도록 요구한다. 새 설정은 `API_INTERNAL_URL`을 필수로 검증하지만, `turbo.json`에는 이를 전달할 `env`·`globalEnv`·`passThroughEnv` 설정이 없다.
- 확인: 두 환경변수를 더미 값으로 주입하고 `turbo run build --filter=@jblog/frontend --dry=json --daemon=false`를 실행했다. 결과는 `envMode: "strict"`이며, 전달 대상으로 추론된 변수는 `NEXT_PUBLIC_SITE_URL`뿐이다. `API_INTERNAL_URL`은 포함되지 않는다.
- 영향: `.env.local` 없이 셸이나 CI 환경변수로 값을 주입하면 Turbo가 `API_INTERNAL_URL`을 제거한다. 따라서 유효한 값을 제공해도 루트 빌드의 frontend 작업은 환경변수 누락으로 실패한다. frontend를 직접 실행하는 빌드·E2E 검증으로는 이 경로를 확인할 수 없다.
- 권고: Turbo의 frontend `build`·`dev` 작업에 필요한 환경변수를 명시한다. 빌드에 영향을 주는 값은 캐시 해시에 반영되도록 `env`에 등록하고, `.env` 파일 없이 더미 환경값을 주입한 루트 실행 경로를 검증한다.
