# M2-VR 검수 r1

## 종합 판정

수정 후 통과 — visual 프로젝트 격리, 허용 오차 유지, CPU 로그 추가는 지시서에 부합한다. 다만 플래그의 공식 근거가 누락되었고, 핵심 완료 조건인 동일 커밋 CI 반복 통과는 확인되지 않았다.

## 지적 사항

### 1. [중간] 렌더링 플래그의 공식 근거 누락

- 위치: `frontend/playwright.config.ts:129`, `docs/work/M2/tasks/M2-VR.md:61`
- 근거: 작업 지시서 「동작 규약」 1은 각 플래그의 공식 문서·Chromium 소스 위치를 config 주석과 인계 노트에 남기도록 요구한다. 현재는 “확인 못 함”으로 기재되어 있고, 필수 검증은 완료로 표시되어 있다.
- 영향: 플래그가 사용하는 Chromium에서 어떤 렌더링 경로를 제어하는지 추적하기 어렵고, 요구된 근거 검증이 끝나지 않은 상태로 기준 이미지가 갱신된다.
- 권고: 네 플래그의 정의·처리 위치를 확인해 기록하고, 확인된 동작과 원인 추정을 구분한다. 예를 들어 `--disable-skia-runtime-opts`의 정의는 Chromium의 [`content/public/common/content_switches.cc`](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/content/public/common/content_switches.cc)에서 확인할 수 있다.

### 2. [중간] 동일 커밋 CI 3회 통과 증거 미확보

- 위치: `docs/work/M2/tasks/M2-VR.md:47`
- 근거: 작업 지시서 「동작 규약」 4·「필수 검증」은 같은 커밋의 CI `e2e` 잡을 3회 이상 실행해 모두 통과하도록 요구한다. 대상 head에는 해당 항목이 미완료이며, 실행별 결과와 CPU 모델 기록이 없다. 협업 문서 `docs/plan/05_collaboration_architecture.md` §10도 필수 검증 전부 충족을 완료 조건으로 정한다.
- 영향: 로컬 반복 실행만으로는 이번 수정의 목적인 CI 러너 간 렌더링 안정성을 판정할 수 없다.
- 권고: push 후 동일 커밋으로 요구된 반복 검증을 수행하고, 대응 기록에 실행 URL·시도 번호·검사 SHA·CPU 모델·`e2e` 결과를 남긴다. 이미 실행했다면 해당 증거를 제공한다. 이는 실패 확정이 아니라 완료 검증 미충족 지적이다.

## 확인한 범위

- 지정된 전체 `git diff`, `git diff --name-only`, `git diff --check`를 확인했다. 변경은 설정·CI·지시서·기준 PNG 24장으로 한정되며, `src/**` 변경은 없다.
- 작업 지시서, 개요 §6-a·§6-b, 협업 §3.4·§4.3-a·§6.2·§6.4-a·§6.5·§10-a·§10, UI 디자인 §11-6을 대조했다.
- Playwright 설정, 시각 회귀 테스트·캡처 헬퍼, 컨테이너 실행 스크립트·Dockerfile, 루트 실행 명령과 CI 워크플로를 검토했다. `threshold: 0`, `maxDiffPixels: 15`, 일반 E2E 설정 및 필수 검사 8개는 유지된다.
- PNG 24장의 base/head 크기를 비교했다. components 375px Light/Dark는 높이가 6793→6789px이고 나머지는 동일하다. home·components 각각 1920·768·375px 표본을 육안 확인했으며, 픽셀 차이 전체가 안티앨리어싱에 한정되는지는 확정하지 않았다.
- 파일은 수정하지 않았다. 산출물을 생성하는 테스트는 실행하지 않았으며, 인계 노트의 실행 결과를 독립 재현 결과로 간주하지 않았다. `gh run list`는 네트워크 연결 실패로 CI 결과를 조회하지 못했다.
