# M2-VR 검수 r2

## 종합 판정

수정 후 통과 — r1의 플래그 근거 누락은 해소되었다. 다만 동일 커밋의 CI `e2e` 3회 통과 증거가 없어, 러너 간 렌더링 안정성에 대한 필수 검증은 미충족이다.

## 지적 사항

### 1. [중간] 동일 커밋 CI 3회 통과 증거 미확보 — r1 미해소

- 위치: `docs/work/M2/tasks/M2-VR.md:47`, `docs/reviews/M2-VR/r1.response.md:6`
- 근거: 작업 지시서 「동작 규약」 4·「필수 검증」은 같은 커밋으로 CI `e2e` 잡을 3회 이상 실행해 모두 통과하도록 요구한다. 해당 항목은 미완료이며, 대응 기록에도 수행 예정만 있다. `docs/plan/05_collaboration_architecture.md` §10은 필수 검증 전부 충족을 완료 조건으로 정한다.
- 영향: 로컬 반복 실행 기록만으로는 이번 수정의 목적인 CI 러너 간 렌더링 안정성을 확인할 수 없다. 현재 증거로는 작업 완료를 판정할 수 없다.
- 권고: push 후 동일 커밋으로 반복 검증하고, 실행 URL·시도 번호·head/base/검사 SHA·CPU 모델·`e2e` 결과를 대응 기록에 남긴다. 실패하면 수정 후 재검수한다. 검수 기록만 추가하는 경우에는 협업 §6.5의 재검수 예외를 적용할 수 있다.

## 확인한 범위

- 지정된 전체 `git diff`, `git diff --name-only`, `git diff --check`와 커밋 이력을 확인했다. diff 공백 오류는 없다.
- 변경 6개 파일과 작업 지시서를 검토하고, 개요 §6-a·§6-b, 협업 §4.3-a·§6.4-a·§6.5·§10-a·§10, UI 디자인 §11-6을 대조했다.
- Playwright 설정, 시각 회귀 테스트·캡처 헬퍼, 컨테이너 실행 스크립트·Dockerfile, 실행 명령과 CI 워크플로를 확인했다. 플래그는 visual 프로젝트에만 적용되며, `threshold: 0`, `maxDiffPixels: 15`, 일반 E2E 설정과 CI 필수 검사 8개는 유지된다.
- r1의 근거 누락은 해소되었다. 남은 세 플래그의 정의·설명은 Chromium 공식 소스의 [content_switches.cc](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/content/public/common/content_switches.cc)와 [display_switches.cc](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/ui/display/display_switches.cc)에서 확인했다. `--font-render-hinting`은 제거되어 있다.
- 기준 PNG 24장이 존재하며, 최종 diff에서 변경된 이미지는 `home-1024-dark.png` 1장이다. 나머지 23장은 base와 동일하다. 이미지 픽셀 비교는 Pillow 미설치로 수행하지 못했다.
- `gh run list`는 GitHub API 연결 실패로 조회하지 못했다. 인계 노트의 테스트 결과는 독립 재현 결과로 간주하지 않았다.
- 파일은 수정하지 않았다. 산출물을 생성하는 `pnpm verify`, E2E·시각 회귀 테스트는 실행하지 않았다.
