# M2-03 검수 r1

## 종합 판정

수정 후 통과 — 검색 결과를 재조회하는 단계에 공개 조건이 누락되어, 비공개 전환 후 수정한 내용이 공개 응답에 포함될 수 있다.

## 지적 사항

### 1. [높음] 검색 결과 재조회에서 비공개 글의 수정 내용이 노출될 수 있음

- 위치: `backend/src/modules/posts/search.service.ts:58`
- 근거: `docs/work/M2/tasks/M2-03.md` 동작 규약 1은 모든 공개 조회에 `status = PUBLISHED AND publishedAt <= now()`를 요구한다. `docs/plan/01_backend_plan.md` §5.1에서도 비공개 전환된 글은 공개 조회 대상에서 제외한다. 검색 ID 조회에는 공개 조건이 있지만, 후속 `findMany`는 ID만 검사하며 두 조회를 묶는 스냅샷도 없다.
- 영향: 검색 ID 조회 직후 관리자가 해당 글을 비공개로 전환하고 초안을 수정하면, 후속 조회가 비공개 상태의 새 제목·요약을 반환한다. 저장된 요약이 없으면 수정된 비공개 본문 앞부분도 자동 요약으로 노출되며, 검색 응답은 공용 캐시에 30초간 저장될 수 있다.
- 권고: 후속 조회에도 공개 조건을 적용하거나, 검색과 응답 데이터 조회를 단일 쿼리 또는 동일한 읽기 스냅샷으로 처리한다. ID 조회와 데이터 조회 사이에 비공개 전환·수정을 끼워 넣는 회귀 테스트를 추가한다.
