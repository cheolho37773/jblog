# M2-06 검수 r1

## 종합 판정

수정 후 통과 — Overlay 카드의 포커스 표시와 긴 제목에서의 FeaturedHero 높이 처리에 중간 심각도 결함이 있다. 관련 테스트가 기본 예시만 확인해 두 문제를 검출하지 못한다.

## 지적 사항

### 1. [중간] Overlay 카드의 포커스 링이 부모 영역에 잘린다

- 위치: `frontend/src/features/posts/components/PostCardOverlay.tsx:21`
- 근거: `docs/ui_design/ui_design_spec.md` §9와 `docs/work/M2/tasks/M2-06.md` 필수 검증은 카드의 포커스 링이 보여야 한다고 규정한다. 카드 전체를 채우는 링크가 `overflow-hidden`인 `article` 안에 있고, 전역 포커스 스타일은 링크 바깥에 `outline: 2px`, `outline-offset: 2px`를 그린다. 따라서 링이 부모의 잘림 영역 밖에 놓인다.
- 영향: 키보드로 Overlay 카드에 도달해도 포커스 링이 보이지 않는다. `frontend/e2e/components/post-cards.spec.ts`의 카드 포커스 검증은 Grid 카드만 대상으로 하므로 이를 놓친다.
- 권고: 포커스 링을 잘리지 않는 바깥 요소에 표시하거나 카드 안쪽에 표시하도록 구성한다. Overlay 카드에서도 키보드 포커스 표시가 실제로 보이는지 검증한다.

### 2. [중간] 긴 Hero 제목이 부모 높이에 반영되지 않는다

- 위치: `frontend/src/features/posts/components/FeaturedHeroCard.tsx:33`
- 근거: `docs/work/M2/tasks/M2-06.md` 필수 검증은 FeaturedHero 카드가 데스크톱에서 루트와 다음 블록을 넘지 않아야 한다고 명시한다. 그러나 768px 이상에서 플로팅 패널은 절대 배치되고, 부모 높이는 이미지 600px와 하단 패딩 64px로 고정된다. 제목 길이에 따른 패널 높이는 반영하지 않는다.
- 영향: 카테고리가 있고 제목이 4줄이면 패널 높이는 약 342px이므로 하단이 루트 기준 702px에 도달해 부모 높이 664px을 넘는다. 더 긴 제목에서는 다음 콘텐츠까지 겹칠 수 있다. 현재 Hero 예시와 E2E는 짧은 제목만 사용한다.
- 권고: 지정된 패널 위치를 유지하면서 실제 패널 높이만큼 부모 공간을 확보한다. 768·1024·1440px에서 여러 줄 제목을 사용해 패널 하단과 다음 블록의 경계를 검증한다.
