# M2-06 검수 r2

## 종합 판정

수정 후 통과 — r1의 포커스 링 잘림과 긴 Hero 제목의 겹침은 코드상 해소됐다. 다만 Hero의 흐름 배치 전환 후 불필요한 하단 padding이 남아 기본 높이 규칙을 위반한다.

## 지적 사항

### 1. [중간] Hero의 하단 여백이 중복 반영되어 기본 높이가 늘어난다

- 위치: `frontend/src/features/posts/components/FeaturedHeroCard.tsx:30`
- 근거: `docs/ui_design/ui_design_spec.md` §5.5는 Hero 기본 전체 높이를 664px로 정한다. `docs/work/M2/tasks/M2-06.md` 필수 검증도 §5.5 수치 준수를 요구한다. 패널을 흐름에 포함하고 `min-height: 664px`를 지정했지만, 기존 `tablet:pb-16`도 유지해 패널 뒤에 64px을 추가한다.
- 영향: 카테고리가 있고 제목이 2줄이면 패널 높이는 262px, 하단은 루트 기준 622px이다. 이미 664px 안에 들어가는데도 루트 높이가 `360 + 262 + 64 = 686px`로 늘어난다. 3줄이면 패널 하단은 662px이지만 루트는 726px이 된다. 다음 섹션이 불필요하게 밀리며, 현재 E2E는 패널 포함 여부만 검사해 이 차이를 검출하지 못한다.
- 권고: 흐름 배치와 최소 높이는 유지하면서 중복 하단 padding을 제거한다. 제목 1·2·3줄에서는 전체 높이 664px을 유지하고, 더 긴 제목에서는 패널을 포함하도록 높이가 늘어나는지 회귀 테스트로 확인한다.
