# M1-04 검수 r2

## 종합 판정

수정 후 통과 — r1의 Section 간격과 경로 변경 종료 테스트 지적은 코드상 반영되었다. 데스크톱 Navbar 높이가 기획과 다른 사항이 남아 있다. 독립 실행한 타입 검사는 통과했다.

## 지적 사항

### 1. [중간] 데스크톱 Navbar 높이가 기획의 100px보다 작다

- 위치: `frontend/src/components/layout/Navbar.tsx:18`
- 근거: `docs/ui_design/ui_design_spec.md` §4.1·§5.1은 데스크톱 Navbar 높이 100px과 세로 패딩 32px을 명시한다. `docs/work/M1/plan.md` §4의 M1-04 완료 기준도 §5.1과 일치하는 레이아웃을 요구한다. 구현은 높이 44px인 로고·메뉴에 `py-3`을 적용하여 하단 테두리 포함 69px 구조가 된다. §11의 의도된 차이 목록에 해당 축소는 없다.
- 영향: 데스크톱에서 Navbar와 내부 요소의 세로 위치가 기획과 달라지고, 후속 본문도 약 31px 위에서 시작한다. 현재 E2E는 요소 표시와 sticky 동작을 검사하지만 Navbar 높이는 검사하지 않는다.
- 권고: 44×44 터치 영역을 유지하면서 데스크톱 Navbar의 전체 높이와 내부 정렬을 명세에 맞춘다. 데스크톱 실제 높이를 검증하는 회귀 검증을 추가한다.
