# M1-04 검수 r4

## 종합 판정

수정 후 통과 — 기존 지적은 코드와 회귀 테스트에 반영되었다. Contact Me 카드의 내부 간격이 명세와 다른 사항이 남아 있다. 독립 실행한 타입 검사는 통과했다.

## 지적 사항

### 1. [중간] Contact Me 카드의 제목과 연락처 사이 간격이 명세보다 작다

- 위치: `frontend/src/components/layout/Footer.tsx:33`
- 근거: `docs/ui_design/ui_design_spec.md` §5.9는 카드 내부 gap을 30px로 지정하며, Newsletter를 Contact Me로 대체해도 박스 크기·여백·배경은 유지하도록 명시한다. 구현은 제목과 연락처 묶음을 감싼 컨테이너에 `gap-4`를 적용해 16px로 표시한다. `docs/work/M1/plan.md` §4의 M1-04 완료 기준은 Footer가 UI §5.9와 일치할 것을 요구한다.
- 영향: 연락처가 제공되면 제목과 연락처 사이 간격이 지정값보다 14px 줄어든다. 현재 카드 테스트는 표시·주소·복사 예외·배경색을 확인하지만 내부 간격은 검사하지 않는다.
- 권고: 제목과 연락처 묶음 사이 간격을 30px로 맞추고, 예시 Footer에서 실제 간격을 확인하는 검증을 추가한다.
