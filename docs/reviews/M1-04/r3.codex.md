# M1-04 검수 r3

## 종합 판정

수정 후 통과 — 기존 Section 간격·경로 변경 종료·Navbar 높이 지적은 코드와 회귀 테스트에 반영되었다. 데스크톱 메뉴의 터치 영역과 Footer 간격에서 명시된 규약과 다른 구현이 남아 있다. 독립 실행한 타입 검사는 통과했다.

## 지적 사항

### 1. [중간] 데스크톱 메뉴 링크의 가로 히트 영역이 44px에 못 미친다

- 위치: `frontend/src/components/layout/NavLinks.tsx:48`
- 근거: `docs/work/M1/tasks/M1-04.md`의 반응형 규약은 Navbar의 모든 조작 요소에 44×44 이상 히트 영역을 요구한다. 링크는 `min-h-11`만 적용하며 최소 너비·가로 패딩·확장 의사 요소가 없다. 데스크톱의 짧은 링크인 Blog는 16px 글자 너비만 클릭 영역이 된다.
- 영향: ≥1024px에서 Blog 링크의 가로 터치 영역이 규약보다 작다. 현재 히트 영역 E2E는 375px에서만 실행하므로, 데스크톱 메뉴 링크는 검사하지 않는다.
- 권고: 시각적 메뉴 간격을 유지하면서 최소 너비 또는 의사 요소로 히트 영역을 확장한다. 1024·1280px에서도 메뉴 링크 전체의 44×44 히트 영역을 검증한다.

### 2. [중간] Footer 링크 목록의 세로 간격이 명세보다 작다

- 위치: `frontend/src/components/layout/Footer.tsx:24`
- 근거: `docs/ui_design/ui_design_spec.md` §5.9는 컬럼 제목과 목록 사이 24px, 목록 항목 사이 8px을 지정한다. 구현은 제목에 `mb-4`로 16px을 적용하고, 목록에는 `gap`을 주지 않는다. `docs/work/M1/plan.md` §4의 M1-04 완료 기준은 §5.9와 일치하는 레이아웃을 요구하며, 해당 축소에 대한 별도 결정은 없다.
- 영향: 데스크톱 Quick Link·Category 목록이 지정된 간격보다 조밀하게 표시된다. Quick Link 6개 기준 항목 사이 여백 40px이 빠지고 제목 아래 여백도 8px 줄어든다. 현재 테스트는 링크 존재·주소·숨김 규칙만 확인한다.
- 권고: 제목 아래 간격을 24px, 목록 항목 간격을 8px로 맞춘다. 모바일의 44px 터치 영역을 유지하고 실제 간격을 확인하는 검증을 추가한다.
