# M2-08 검수 r1

## 종합 판정

수정 후 통과 — 상세 페이지의 오류가 목록 전용 오류 경계에 잡혀, 지정된 공통 오류 화면이 표시되지 않는다.

## 지적 사항

### 1. [중간] 상세 조회 실패에 공통 오류 화면이 적용되지 않음

- 위치: `frontend/src/app/(site)/error.tsx:10`
- 근거: `docs/work/M2/tasks/M2-08.md`의 「404·오류 화면」은 공통 오류 문구와 다시 시도 버튼, Home 링크를 요구한다. 그러나 `/blog/[slug]`에는 기존 `frontend/src/app/(site)/blog/error.tsx:7`이 더 가까운 오류 경계로 적용된다.
- 영향: 상세 조회가 401·5xx·네트워크 오류로 실패하면 “글 목록을 불러오지 못했습니다”가 표시되고 Home 링크가 없다. 새 `ErrorNotice`는 이 경로에 적용되지 않는다. 거부 E2E도 상태 코드와 alert 유무만 검사하므로 이 차이를 잡지 못한다.
- 권고: 목록 전용 경계를 유지하면서 상세에는 `ErrorNotice`를 사용하는 더 가까운 경계를 둔다. 오류 E2E에 공통 문구·다시 시도 버튼·Home 링크 검증을 추가한다.

- 작업 지시서, 개요 §6-b, 프론트 §4·§5.3·§6.3·§9, 백엔드 §4.5·§5.7, 접근 통제 문서의 원문 보호 규칙, 협업 §5.2·§10-a, UI §7.3·§7.7·§8·§9.
