# M1-02 검수 r4

## 종합 판정

수정 후 통과 — 이전 지적의 수정은 확인했다. 그라디언트 텍스트의 Light 배경 대비가 접근성 기준에 미달하는 중간 지적 1건이 있다.

## 지적 사항

### 1. [중간] 그라디언트의 밝은 구간이 큰 글자 대비 기준에 미달한다

- 위치: `frontend/src/app/globals.css:86`~`88`
- 근거: `docs/ui_design/ui_design_spec.md` §3.4는 Light 배경 대비 검증을 요구하고, §9는 Display 그라디언트 텍스트에도 최소 3:1을 적용한다. 실제 시작 색의 흰 배경 대비는 primary `#FF8660` **2.378:1**, orange `#F77B53` **2.654:1**, blue `#4CA2F6` **2.690:1**이다. M1-02 지시서의 스크린샷 보정 결정에는 대비 기준 예외가 없다.
- 영향: Light 배경에서 해당 유틸을 제목에 사용하면 밝은 색 구간의 글자가 큰 글자 기준에도 미달한다. 현재 정적 테스트는 그라디언트 형식만 검사하므로 이를 검출하지 못한다.
- 권고: Light 배경에서 전체 그라디언트가 3:1 이상이 되도록 색을 보정하거나, 대비를 확보하는 Light 전용 표현을 결정한다. 지시서의 중간 보고 조건에 따라 결정 사항을 기록하고 그라디언트 대비 검사도 추가한다.
