# M2-10 검수 r2

## 종합 판정

수정 후 통과 — 후행 슬래시 문제는 수정됐다. 다만 사이트 주소에 경로가 포함되면 복사 링크와 canonical이 달라지는 경우가 남아 있다.

## 지적 사항

### 1. [중간] 사이트 주소에 경로가 있으면 복사 링크와 canonical 불일치

- 위치: `frontend/src/features/posts/lib/post-url.ts:6`
- 근거: `docs/work/M2/tasks/M2-10.md`의 「적용 규칙 — 링크 복사」는 canonical과 동일한 절대 주소를 요구한다. `new URL('/blog/…', siteUrl)`은 사이트 주소의 경로를 버리지만, 설치된 Next.js의 메타데이터 해석기는 `metadataBase`의 경로를 유지한다. 공개 환경변수 스키마는 경로가 포함된 URL도 허용한다.
- 영향: `NEXT_PUBLIC_SITE_URL=https://example.com/base/`, slug `x`에서 canonical은 `https://example.com/base/blog/x`, 복사 링크는 `https://example.com/blog/x`다. Node 실행으로 불일치를 재현했다. 새 테스트는 루트 주소의 후행 슬래시만 비교하므로 이 경우를 검출하지 못한다.
- 권고: canonical과 복사 링크가 동일한 절대 URL 계산 결과를 사용하도록 통일하고, 경로가 포함된 사이트 주소에서도 두 값이 일치하는 회귀 테스트를 추가한다.

## 확인한 범위

- 기준 문서: 루트·프론트엔드 `AGENTS.md`, M2-10 지시서, 개요 결정사항·§6-a·§6-b, 복사 방지 계획 Part 2, 프론트엔드 §7.1-a, 협업 §5.2·§10·§10-a, UI §7.3·§9·§11.
- 변경 코드·테스트: 보호 래퍼, 이벤트 판정·토스트, CSS, 코드·링크·주소 복사, Footer, 이미지 드래그 방지, 개발 페이지, 신규 단위·E2E 테스트, URL 함수·JSON-LD 및 기록 문서.
- 읽기 전용 명령: 지정 범위의 `git diff`, `git diff --name-only`, `git diff --stat`, `git diff --check`, 커밋별 변경 내역 및 관련 파일 조회. 공백 오류 없음.
