# M2-10 검수 r1

## 종합 판정

수정 후 통과 — 사이트 주소 끝에 `/`가 있는 유효한 설정에서 복사되는 링크가 canonical 주소와 달라진다.

## 지적 사항

### 1. [중간] 사이트 주소의 후행 슬래시로 잘못된 공유 링크 생성

- 위치: `frontend/src/app/(site)/blog/[slug]/page.tsx:102`
- 근거: `docs/work/M2/tasks/M2-10.md`의 「링크 복사」 규칙은 canonical과 동일한 절대 주소를 요구한다. 현재는 환경변수에 경로를 문자열로 이어 붙인다. `frontend/src/lib/env.public-schema.ts`는 후행 `/`가 있는 주소도 허용한다.
- 영향: `NEXT_PUBLIC_SITE_URL=https://example.com/`이면 `https://example.com//blog/example-post`가 복사된다. 설치된 Next.js의 메타데이터 URL 해석 함수로 확인한 canonical은 `https://example.com/blog/example-post`다. 공유 링크의 경로가 달라져 접근 실패나 중복 주소가 발생할 수 있다.
- 권고: canonical과 링크 복사가 동일한 URL 정규화 로직을 사용하도록 하고, 사이트 주소의 후행 `/` 유무에 대한 회귀 테스트를 추가한다.
