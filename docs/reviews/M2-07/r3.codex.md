# M2-07 검수 r3

## 종합 판정

수정 후 통과 — 검토 범위에서 추가 코드 결함은 확인하지 않았다. 이전 지적의 상태 초기화·요청 취소는 메모리 실행으로 확인했으나, 필수 Docker 빌드 검증이 미완료로 남아 있다.

## 지적 사항

### 1. [중간] 백엔드 없는 Docker 빌드 필수 검증이 미완료

- 위치: `docs/work/M2/tasks/M2-07.md:93`
- 근거: 작업 지시서 「필수 검증 → 회귀」는 일반·Docker 빌드의 백엔드 무의존 검증을 요구하지만 Docker 항목이 미확인이다. `docs/plan/05_collaboration_architecture.md` §10은 필수 검증이 모두 완료되어야 한다고 규정한다.
- 영향: 공통 layout에 서버 조회가 추가된 상태에서 컨테이너 빌드가 백엔드 없이 완료되는지 확정할 수 없다.
- 권고: 검수 대상 head에서 백엔드 없이 프론트 Docker 빌드를 수행하고, 해당 SHA·명령·종료 코드가 확인되는 실행 근거를 남긴다. 구현자의 기존 성공 설명은 독립 검증 근거로 사용하지 않았다.

## 확인한 범위

- 지정 SHA 간 `git diff`, `git diff --name-only`, `git diff --numstat`, `git diff --check` 확인. 공백 오류 없음.
- `/blog` 페이지·오류 경계, 공통 layout, 필터 전환, Load More·경계 컴포넌트, 쿼리 정규화·목록 병합, 관련 단위·E2E·픽스처 변경 검토.
- 작업 지시서와 관련 기획의 API 계약, 렌더링·캐시, 민감 정보, 접근 통제, 소유권, 디자인 규칙 대조.
- 실제 컴포넌트를 Node·TypeScript·React·jsdom으로 메모리 실행하여 다음 5개 확인 통과: 자체 URL 변경 후 카드 유지, 캐시 이동 시 목록 초기화, 서버 key 변경 시 동일 slug 정보 갱신·기존 요청 취소, 늦은 응답 무시, 새 인스턴스의 재요청.
- 위 실행은 API·라우터 훅·표시용 하위 컴포넌트를 대체했다. 실제 Next.js 브라우저 이동 검증을 대신하지 않는다.
- 전체 테스트·E2E·`pnpm verify`·일반/Docker 빌드·시각 회귀는 재실행하지 않았다. 변경된 기준 이미지 12장의 시각적 적합성은 미확인이다.
- 파일 수정 없음. 기존 미추적 `docs/reviews/M2-07/r3.codex.md`는 읽거나 검수 근거로 사용하지 않았다.
