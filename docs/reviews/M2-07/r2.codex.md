# M2-07 검수 r2

## 종합 판정

수정 후 통과 — Load More 상태 동기화에 두 가지 결함이 남아 있다. 서버가 전달한 글 정보 변경을 놓치고, 이동 전에 시작한 요청이 이동 후 목록과 URL을 다시 변경할 수 있다.

## 지적 사항

### 1. [중간] slug가 같은 글의 최신 정보가 반영되지 않음

- 위치: `frontend/src/features/posts/components/LoadMoreGrid.tsx:46`
- 근거: `docs/plan/02_frontend_plan.md` §4 및 `docs/plan/01_backend_plan.md` §5.7-⑤는 새 페이지 요청에 최신 데이터를 반영하도록 한다. 그러나 서버 데이터 변경 여부를 페이지·전체 페이지 수·slug 순서만으로 판단해 제목·커버·카테고리 등의 변경을 무시한다.
- 영향: 같은 URL로 다시 이동하여 서버가 수정된 글 정보를 전달해도 slug와 페이지 구성이 같으면 이전 카드가 유지된다. 메모리 실행에서 동일 slug의 제목을 `Before`에서 `After`로 바꾼 props를 전달했지만 화면에는 `Before`가 남았다.
- 권고: 카드에 표시하는 데이터 변경도 동기화 기준에 포함한다. 동일한 내용의 새 배열에서는 추가 로드 상태를 유지하되, 같은 slug의 제목·커버 등이 달라지면 최신 값이 반영되는 회귀 테스트를 추가한다.

### 2. [중간] 같은 서버 값으로 이동하면 이전 Load More 응답을 폐기하지 못함

- 위치: `frontend/src/features/posts/components/LoadMoreGrid.tsx:73`, `frontend/src/features/posts/components/LoadMoreGrid.tsx:85`, `frontend/src/features/posts/components/LoadMoreGrid.tsx:110`
- 근거: 작업 지시서 `docs/work/M2/tasks/M2-07.md`의 페이지·Load More 규칙과 `docs/plan/02_frontend_plan.md` §6.2는 이동한 주소에 맞는 목록 상태를 요구한다. 주소 변경으로 상태를 초기화해도 요청 유효성 판단은 `serverSignature`만 사용하므로, 서버 값이 같은 이동에서는 이전 요청이 계속 유효하다.
- 영향: `/blog?page=1`에서 Load More 요청을 지연시키고 Navbar Blog로 `/blog`에 이동하면 버튼은 활성화되지만 `requestInFlight`가 남아 재클릭이 무시된다. 이후 이전 응답이 도착하면 카드가 추가되고 주소가 다시 `/blog?page=2`로 바뀐다. 이 흐름을 메모리 실행으로 재현했다.
- 권고: 사용자 이동마다 요청 세대를 갱신하거나 기존 요청을 취소하여 이전 응답을 폐기한다. 진행 중 플래그도 함께 정리하고, 지연된 Load More 요청 중 Navbar 이동 후 목록·주소가 유지되고 새 요청이 가능한지 검증한다.

## 확인한 범위

- 지정 SHA의 `git diff`, `git diff --name-only`, `git diff --numstat`, `git diff --check` 확인. 공백 오류 없음.
- `/blog` 페이지·오류 경계, 공통 layout, 필터 전환, Load More, 쿼리 정규화·목록 병합 및 관련 단위·E2E·픽스처 변경 검토.
- 작업 지시서와 관련 기획의 공개 API·렌더링·캐시·민감 정보·접근 통제·소유권·디자인 규칙 대조.
- Node·TypeScript·React·jsdom으로 실제 `LoadMoreGrid`를 메모리에서 실행해 두 결함 재현. API·라우터 훅·표시용 하위 컴포넌트는 대체했으며 브라우저 E2E 재현은 수행하지 않았다.
- 전체 테스트·`pnpm verify`·일반/Docker 빌드·시각 회귀는 재실행하지 않았다. 구현자의 실행 기록은 독립 검증 근거로 사용하지 않았다.
- 변경된 기준 이미지 12장은 변경 범위만 확인했으며 시각적 적합성은 미확인이다.
- 파일 수정 없음. 기존 미추적 `docs/reviews/M2-07/r2.codex.md`는 검수 근거에서 제외하고 그대로 두었다.
