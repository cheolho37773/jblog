# M0-04-fix 검수 r1

## 종합 판정

수정 후 통과 — 파일 경로 계산, 프로세스 값 우선 병합, 파일 부재 처리, `createApp(rawEnv)` 격리는 규약에 부합한다. 다만 실제 기동에 관한 필수 성공 검증의 완료 근거가 없어 완료 기준을 충족했다고 판단할 수 없다.

## 지적 사항

### 1. [중간] 실제 시작 경로의 필수 성공 검증이 누락되어 있다

- 위치: `docs/work/M0/tasks/M0-04-fix.md:31`
- 근거: 지시서 「필수 검증」은 스크래치 클론에서 파일만으로 기동, 셸 포트 우선 적용, 파일 없이 셸 값만으로 기동, 필수 값 부재 시 실패를 확인하도록 요구한다. 추가된 `env.source.spec.ts`의 9개 테스트는 보조 함수만 호출하며 `readProcessEnv()`와 실제 시작 경로를 검증하지 않는다. 해당 성공 항목은 미체크 상태이고, 변경 산출물에도 실행 결과가 없다. 이는 `docs/plan/05_collaboration_architecture.md` §10의 필수 검증 항목별 완료 조건을 충족하지 못한다.
- 영향: 보조 함수 테스트가 통과하더라도 실제 빌드 결과의 파일 위치나 시작 스크립트 연결에 문제가 있으면 이번 버그의 해결 여부를 확인할 수 없다.
- 권고: 스크래치 클론과 자리표시자 값으로 네 가지 기동 시나리오를 실행하고, 대상 SHA·명령·종료 상태·실제 수신 포트 등 재검증 가능한 결과와 항목별 완료 상태를 기록한다. 경로와 환경변수 값은 출력에서 제외한다.

## 확인한 범위

- 지정된 전체 `git diff`, `git diff --name-only`, `git diff --check`, 커밋 이력과 역할 trailer를 확인했다. HEAD는 지정 SHA와 일치했다.
- 변경 파일 3개 전체와 관련 시작 경로·설정을 검토했다: `main.ts`, `bootstrap.ts`, `app.module.ts`, 환경변수 검증 구현·테스트, 기존 e2e, Jest·TypeScript·Nest 설정, 패키지 스크립트.
- 기준 문서: 개요의 결정사항·§6-a·§6-b, 백엔드 §2·§6, 협업 §5.2·§10-a·§10, M0-04 및 M0-04-fix 지시서.
- Node 24.22.3에서 백엔드 `tsc --noEmit --incremental false`, 변경 TypeScript 파일 ESLint, 변경 파일 Prettier 검사가 모두 통과했다. `git diff --check`도 통과했다.
- 파일 쓰기가 필요한 신규 단위 테스트·빌드·스크래치 기동 검증은 읽기 전용 제한으로 실행하지 않았다. 전체 회귀 테스트의 통과 여부는 독립 확인하지 않았다.
- 코드·문서 및 저장소 `.env*` 파일은 수정하거나 생성하지 않았으며, 실제 환경 파일을 읽지 않았다.
