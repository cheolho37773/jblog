# M1-05 검수 r1

## 종합 판정

수정 후 통과 — 중간 지적 2건이다. 규칙 준수 검사의 대상 누락과 시각 회귀의 날짜 의존성을 수정해야 한다.

## 지적 사항

### 1. [중간] 규칙 준수 검사에서 body 자체가 누락된다
- 위치: `frontend/e2e/components/rule-compliance.spec.ts:139`
- 근거: `docs/work/M1/tasks/M1-05.md` 동작 규약 9는 렌더 결과의 색·폰트 계산값을 모두 수집하도록 요구한다. 현재 순회는 `html`과 `body`의 자손만 포함하며 `body` 자체는 검사하지 않는다.
- 영향: `body`에 토큰 밖 배경색·테두리색·의사 요소 색이 적용되어도 B 검사가 통과할 수 있다. 실제 수집 함수를 모의 DOM으로 메모리 실행한 결과, body의 배경색을 허용 목록 밖으로 설정해도 body는 검사되지 않고 지적 결과가 빈 배열이었다.
- 권고: 검사 대상에 `document.body`를 포함하고, body의 배경색과 의사 요소에 토큰 밖 색을 주입하면 실패하는 대조 검증을 추가한다.

### 2. [중간] 현재 연도가 기준 이미지에 포함되어 연도 변경 시 시각 회귀가 실패한다
- 위치: `frontend/e2e/helpers/visual.ts:15`, `frontend/e2e/visual/home.spec.ts:11`
- 근거: `docs/work/M1/tasks/M1-05.md` 동작 규약 6·7은 캡처 상태를 고정하고 반복 가능한 비교를 요구한다. 캡처는 날짜를 고정하지 않으며, `frontend/src/components/layout/Footer.tsx:136`은 `new Date().getFullYear()`를 렌더링한다. 커밋된 `home-375-light.png`에서도 `© 2026`을 확인했다.
- 영향: 2027년에 같은 커밋을 새로 빌드하면 저작권 연도가 달라져 코드 변경 없이 시각 회귀와 필수 `e2e` 검사가 실패한다. Footer가 포함된 `/dev/components` 기준 이미지도 영향을 받는다.
- 권고: 시각 회귀 환경에서 서버 빌드·렌더링까지 날짜를 고정하거나, 비교 대상에서 변동하는 연도 부분을 안정적으로 처리한다. Footer는 서버에서 렌더링되므로 브라우저 시계만 고정해서는 충분하지 않다.
