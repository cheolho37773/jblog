# M2-04 검수 r2

## 종합 판정

통과 — 검토 범위에서 수정이 필요한 결함을 발견하지 않았다. r1의 공개 기준 시각 불일치는 요청당 하나의 `asOf`를 모든 조회에 전달하도록 수정됐으며, 예약 발행 경계를 통과하는 회귀 테스트도 추가됐다. 실행 검증에는 아래 제한이 있다.

## 지적 사항

지적 사항 없음.

## 확인한 범위

- 지정 base~head의 `git diff`, `git diff --name-only` 및 변경된 구현·테스트·작업 문서를 검토했다. 현재 HEAD는 지정 SHA와 일치한다.
- M2-04 지시서와 개요 §6-a·§6-b, 백엔드 §4.5·§5.1·§5.6·§5.7·§5.8, 접근 통제 Part 2, 협업 §5.2·§10-a·§10 및 소유권 규칙을 대조했다.
- 키 검증의 상수 시간 비교, 환경변수 필수 검증, 로그 마스킹, 인증 우선 실행, 이전 slug 처리, 캐시 헤더, 읽기 전용 스냅샷, 공개 조회 규칙 재사용과 필수 검증 테스트를 확인했다.
- OpenAPI·스키마·생성 타입의 변경이 없음을 확인했다.
- `git diff --check`와 `node node_modules/typescript/bin/tsc --noEmit --incremental false -p backend/tsconfig.json`은 통과했다.
- 단위 테스트는 `--runInBand --no-cache`로 시도했으나, Jest의 임시 캐시 쓰기가 읽기 전용 환경에서 `EPERM`으로 거부되어 테스트 실행 전에 종료됐다.
- e2e·통합 테스트·Docker 빌드·`pnpm verify`·`contract:check`는 실행하지 않았다. 구현자의 통과 기록은 독립 검증 근거로 사용하지 않았다.
- 기존 미추적 파일 `docs/reviews/M2-04/r2.codex.md`는 검수 대상에서 제외했다. 파일을 수정하지 않았다.
