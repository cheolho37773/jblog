## 표시 규칙 (오케스트레이터 확정)

| 항목 | 규칙 |
|---|---|
| 날짜 | `publishedAt`을 **Asia/Seoul** 기준 날짜로 보여 준다. 형식은 `2026.01.05`이고, `<time dateTime="원래 ISO 값">`으로 감싼다 |
| 읽는 시간 | `5 min read`(UI §5.3 예시 문구). `readingMinutes`가 1 이하면 `1 min read` |
| 작성자 자리 | 작성자가 1명이므로 아바타·이름은 넣지 않는다(UI §5.3 "날짜 + 읽는 시간으로 대체"). 두 값 사이는 §5.3 gap(md 20 / sm 24) |
| 카드 링크 | 카드 전체가 하나의 링크(`/blog/{slug}`)다. 접근 가능한 이름은 제목이다. 카테고리 배지는 카드 안에서는 링크가 아니다(중첩 링크 금지) |
| 썸네일 | 일반 `<img loading="lazy" decoding="async">`, `alt=""`(제목이 이름이므로 장식). 비율 3:2(360×240)로 자리를 먼저 잡는다. `coverImageUrl`이 없으면 같은 비율의 `bg-subtle` 자리 표시 |
| 카테고리 없음 | `category`가 `null`이면 배지를 그리지 않는다 |
| 제목 | `PostCardGrid`는 최대 3줄로 자른다(`line-clamp-3`). 헤딩 단계는 props(`headingLevel`, 기본 3)로 받는다 |
| hover | `PostCardGrid`: 카드 `translateY(-4px)` + `shadow-md`, 썸네일 `scale(1.03)`(overflow hidden). `prefers-reduced-motion`이면 이동·확대 없음. 포커스 링은 hover와 별개로 항상 보인다 |
| CategoryChips | 첫 칩은 `All`(`/blog`). 각 칩은 `/blog?category={slug}`, 이름 옆에 글 수는 넣지 않는다. 선택된 칩은 Badge `solid` + `aria-current="page"`, 나머지는 `soft`. 가로 스크롤(줄바꿈 없음), `nav aria-label="카테고리"`. 터치 타겟 44 |
| 스켈레톤 | `PostCardSkeleton`: 카드와 같은 크기·구조(썸네일·제목 2줄·메타), `bg-subtle` + shimmer(`prefers-reduced-motion`이면 정지), `aria-hidden="true"` |

## 테스트 대상 인터페이스 (`frontend/src/features/posts/components/`)

| 컴포넌트 | Props | 역할·이름 |
|---|---|---|
| `AuthorMeta` | `{ publishedAt: string; readingMinutes: number; size?: 'md' \| 'sm'; onImage?: boolean }` | `time[dateTime]` + 읽는 시간 글자. `onImage`면 글자색 `on-primary` |
| `PostCardGrid` | `{ post: PostSummaryDto; headingLevel?: 2 \| 3 }` | `article` > `a[href="/blog/{slug}"]`(이름=제목) > 썸네일·배지(soft)·`h{n}` 제목·AuthorMeta |
| `PostCardOverlay` | `{ post: PostSummaryDto; headingLevel?: 1 \| 2 }`(기본 2) | 1216×450 비율, 배경 이미지 + `overlay`, 아래 정렬. 배지(solid)·제목(on-primary, h1 36/40 스타일)·AuthorMeta(onImage). 카드 전체 링크 |
| `FeaturedHeroCard` | `{ post: PostSummaryDto; headingLevel?: 1 \| 2 }`(기본 2) | UI §5.5: 이미지 1216×600 + `overlay`, 플로팅 카드(데스크톱 left 64·top 360·폭 598·padding 40·gap 24·`surface`·`border`·`shadow-md`). 모바일은 카드가 이미지 아래로 겹침 없이 쌓인다. 배지(solid)·제목(h1 36/40)·AuthorMeta. 카드 전체 링크 |
| `CategoryChips` | `{ categories: CategoryWithCountDto[]; activeSlug?: string }` | `nav[aria-label="카테고리"]` > 링크 칩들 |
| `PostCardSkeleton` | `{}` | `aria-hidden` |

- `/dev/components`에 섹션을 추가한다(`dev-posts-cards`). 예시 데이터는 페이지 안의 상수로 둔다(생성 타입 `satisfies`). 이미지는 E2E 픽스처 경로 `/uploads/fixtures/*`이고, 개발 서버에서는 M2-05에서 추가한 rewrite로 보인다
  - 카드 3장: 커버 있음·없음, 긴 제목(3줄 clamp 확인용), 카테고리 없음 포함
  - Overlay 1장, FeaturedHero 1장, 칩(선택 상태 포함), 스켈레톤 3장

## 필수 검증

- 성공
  - [ ] 각 컴포넌트가 표의 역할·이름·링크를 갖는다. 날짜는 Asia/Seoul 기준이고 `dateTime`은 원래 값이다(UTC 자정 경계 사례 포함)
  - [ ] UI §5.4~§5.6 수치(카드 padding·gap·radius, 썸네일 비율·radius, 오버레이·플로팅 카드 위치·크기)가 계산값과 같다(E2E spec-values 방식, 1440 기준)
  - [ ] hover 시 이동·그림자·확대, `prefers-reduced-motion`이면 없음
  - [ ] 375·768·1024·1440에서 가로 스크롤이 없고 FeaturedHero 카드가 겹치지 않는다
  - [ ] 시각 회귀: components 10장 기준 이미지 갱신(새 섹션), 나머지 24장 불변, 컨테이너 3회 통과
- 거부
  - [ ] 카드 안에 중첩 링크가 없다. 카테고리 `null`이면 배지가 없다. 커버가 없으면 `img`가 없고 자리 표시만 있다
  - [ ] 토큰 밖 색이 없다(rule-compliance). 오버레이 위 글자는 `on-primary`다
  - [ ] axe serious·critical 0(`/dev/components` Light/Dark)
  - [ ] 칩·카드 포커스 링이 보이고, 칩 터치 타겟이 44 이상이다
- 회귀
  - [ ] 기존 단위·E2E, `pnpm verify`가 통과한다
