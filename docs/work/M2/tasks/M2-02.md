## 추가 토큰 (오케스트레이터 확정)

| UI 시맨틱 토큰 | 원시 변수 | Tailwind 변수 | Light | Dark | 용도 |
|---|---|---|---|---|---|
| `--color-code-bg` | `--code-bg` | `--color-code-bg` | `#F6F6F7` | `#141624` | 코드 블록 배경 (UI §7.3). Light는 `bg-subtle`과 같은 값이지만, 용도가 달라 따로 둔다 |

- 형식은 M1-02·M1-08·M1-10과 같다. 원시 변수는 최상위 `:root`·`[data-theme='dark']`에 hex로 두고, `@theme inline`에서 연결한다
- 인라인 코드 글자는 새 토큰을 만들지 않고 기존 `primary-text`를 쓴다. §9에서 강조색 글자는 `primary-text`로 정했기 때문이다. 링크도 같다

## 같은 PR의 기획서 갱신 (오케스트레이터 작성)

UI §7.3 표를 토큰 이름으로 바꾼다.

| 항목 | 바꾸는 내용 |
|---|---|
| 코드 블록 | bg `--color-code-bg` |
| 인라인 코드 | color `--color-primary-text` |
| 링크 | `--color-primary-text` |

§3.3 시맨틱 토큰 표에 `code-bg` 행을 추가한다.
