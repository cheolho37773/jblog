## 적용 규칙 (04 Part 2 그대로, 오케스트레이터 보충)

| 항목 | 규칙 |
|---|---|
| 적용 위치 | `(site)` 공통 틀(현재 `app/SiteChrome.tsx` — 루트 `not-found`도 이 틀을 쓴다)의 루트 래퍼에 `.content-protected`, `CopyGuard`를 그 안에 1번 마운트. `(site)` 밖(`/dev/**`, 루트 `app/error.tsx`)에는 적용하지 않는다 |
| CSS | 04 §2.2 ① 그대로: 선택 금지, `-webkit-touch-callout: none`, 입력 요소·`[contenteditable=true]`·`.allow-select`는 선택 허용, `img` 드래그 금지, 인쇄 시 `main` 숨김 + `이 콘텐츠는 인쇄할 수 없습니다.` |
| `CopyGuard` | 04 §2.2 ② 표와 "예외 판정 규칙" 코드(`isEditableContext`·`isAllowedTextSelection`) 그대로. `document`에 한 번 등록, 언마운트 시 해제. 판정 함수는 **순수 함수로 분리**해 단위 테스트한다 |
| 단축키 | `Cmd/Ctrl + S·P` 항상 차단 · `C·X`는 입력 요소 문맥이거나 선택이 `.allow-select` 안일 때만 허용 · `A`는 입력 요소 문맥에서만 허용 · `F` 허용. Mac은 `metaKey`, 그 외는 `ctrlKey` 둘 다 본다 |
| 안내 토스트 | 차단했을 때 `콘텐츠 복사가 제한되어 있습니다`. **같은 토스트는 3초에 1번만**. `role="status"`(`aria-live="polite"`), 화면 아래 가운데, 3초 뒤 사라짐. 인쇄 단축키 차단도 같은 토스트 |
| 이미지 | `MdImage`, 카드 썸네일·커버 `img`에 `draggable={false}` |
| 코드 복사 버튼 | `CodeBlock` 버튼 클릭 → `navigator.clipboard.writeText(코드 원문)`(원문은 렌더된 `pre`의 텍스트에서 얻는다, 줄바꿈 유지). 성공 시 아이콘을 체크로 2초, `aria-live`로 `복사됨`. 실패(권한 거부·비보안 문맥)면 `복사하지 못했습니다` 안내, 예외를 삼키지 않고 상태로 표시. 코드 텍스트 드래그 선택은 막는다(`.allow-select` 아님) |
| 링크 복사 | 글 상세 상단 메타 줄(AuthorMeta 오른쪽, 모바일은 아래 줄)에 `링크 복사` 버튼. canonical 절대 주소(`/blog/{현재 slug}`)만 복사. 성공 `링크를 복사했습니다`, 실패 `복사하지 못했습니다`(같은 `aria-live`) |
| 주소 복사 | Footer Contact Me 카드의 이메일 옆 `주소 복사` 버튼(이메일 주소만 복사). 이메일 값이 없으면 버튼도 없다(Footer는 값이 없으면 카드를 숨긴다 — 이메일 값은 M4 프로필 API에서 들어온다). 성공·실패 안내는 위와 같다 |
| 클립보드 API | `navigator.clipboard.writeText`는 `copy` 이벤트를 내지 않아 `CopyGuard`와 충돌하지 않는다(04 §2.2 ③). 세 버튼이 같은 복사 훅/함수를 쓴다 |
| JSON-LD | `articleBody` 없음(M2-08에서 이미 없음, 회귀 고정) |

## 확인용 개발 페이지 (오케스트레이터 판정)

- 지금 `(site)` 화면에는 연락처 값이 없어(M4) "연락처 예외·주소 복사"를 실제 페이지에서 볼 수 없다. **`/dev/protection`**(기존 `/dev/*`와 같은 개발 전용 규칙, 운영 빌드 제외)을 만들고, 이 페이지에서만 `SiteChrome`과 같은 보호 래퍼 + `CopyGuard`를 마운트한다. 내용: 본문 문단, 코드 블록(`CodeBlock`), 검색 입력, `.allow-select` 연락처(이메일·GitHub 텍스트 + 주소 복사), 연락처와 본문에 걸친 문단. Footer 예시는 예시 값(`example.com` 도메인)으로 넘긴다
- 실제 `(site)` 페이지(상세 글 — 코드 블록 있음, Home, 검색)에서도 본문 선택·복사·우클릭·인쇄 차단과 검색창 예외를 E2E로 본다
- 보호 적용 래퍼는 `SiteChrome`과 `/dev/protection`이 **같은 컴포넌트**를 쓴다(테스트한 것과 실제가 같도록)
