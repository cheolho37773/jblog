## 확인용 개발 페이지 (오케스트레이터 판정)

- 지금 `(site)` 화면에는 연락처 값이 없어(M4) "연락처 예외·주소 복사"를 실제 페이지에서 볼 수 없다. **`/dev/protection`**(기존 `/dev/*`와 같은 개발 전용 규칙, 운영 빌드 제외)을 만들고, 이 페이지에서만 `SiteChrome`과 같은 보호 래퍼 + `CopyGuard`를 마운트한다. 내용: 본문 문단, 코드 블록(`CodeBlock`), 검색 입력, `.allow-select` 연락처(이메일·GitHub 텍스트 + 주소 복사), 연락처와 본문에 걸친 문단. Footer 예시는 예시 값(`example.com` 도메인)으로 넘긴다
- 실제 `(site)` 페이지(상세 글 — 코드 블록 있음, Home, 검색)에서도 본문 선택·복사·우클릭·인쇄 차단과 검색창 예외를 E2E로 본다
- 보호 적용 래퍼는 `SiteChrome`과 `/dev/protection`이 **같은 컴포넌트**를 쓴다(테스트한 것과 실제가 같도록)

**구현자 요구 (계약)**

- `components/protection/guard-rules.ts`: `isEditableContext(event: Event): boolean`, `isAllowedTextSelection(selection?: Selection | null): boolean`(인자 생략 시 `window.getSelection()`), `shouldBlockShortcut(event: KeyboardEvent): boolean`(`metaKey || ctrlKey` 둘 다 수정키로 본다, 키는 대소문자 무시, 수정키 없으면 false).
- `components/protection/CopyGuard.tsx`: `export function CopyGuard()`. `document`에 `copy·cut·contextmenu·dragstart·selectstart·keydown`을 각 1번 등록, 언마운트 시 같은 함수 해제. 토스트 문구 `콘텐츠 복사가 제한되어 있습니다`는 `role="status"` + `aria-live="polite"` 영역 안, 3초에 1번, 3초 뒤 사라짐, 화면 아래 가운데. copy·cut·C/X·P 차단 시 토스트(S·A·contextmenu 등의 토스트 여부는 테스트하지 않는다). 토스트가 없을 때는 문구 텍스트가 DOM에 없어야 한다(빈 live 영역은 허용).
- `components/protection/ProtectedShell.tsx`: `export function ProtectedShell({ children })` = `.content-protected` 루트 + `CopyGuard` 1회. `SiteChrome`과 `/dev/protection`이 함께 쓴다. `main`이 이 래퍼의 자손이어야 하고, 페이지당 `.content-protected`는 정확히 1개다. 인쇄 CSS는 04 §2.2 ① 그대로(`::after`의 `content`에 `이 콘텐츠는 인쇄할 수 없습니다.`, `display:block`).

Footer 예시 `contact={{ email: 'hello@example.com', githubUrl: 'https://github.com/example' }}`. `data-theme` 토글은 기존 dev 페이지처럼 동작(axe가 테마를 고정하므로 필수는 아님).
- 측정 방법: `keydown`·`contextmenu`·`dragstart`의 `defaultPrevented`는 `window` 버블 리스너로 읽는다(CopyGuard는 `document`에서 먼저 처리해야 한다). 클립보드는 sentinel을 먼저 쓰고 차단 후 그대로인지 본다. 인쇄는 `emulateMedia({media:'print'})` 후 `main`의 computed `display`와 래퍼 `::after`의 `content`·`display`.

**자동화하지 못한 항목**: iOS Safari·Android Chrome 길게 누르기 복사 메뉴(`-webkit-touch-callout`는 Chromium에서 읽을 수 없어 CSS도 미검증), 실제 인쇄 다이얼로그·PDF 저장, 실제 `Cmd+S` 저장 다이얼로그(`defaultPrevented`로만 확인), 시각 회귀(손대지 않음).

**보고 사항**: 지시서 "주소 복사 … 성공·실패 안내는 위와 같다"가 `링크를 복사했습니다`를 그대로 쓰는지 불명확하다(이메일에는 어색). 테스트는 `복사했습니다|복사됨`을 허용하고, 문구는 오케스트레이터가 확정하면 정확 일치로 조인다.
