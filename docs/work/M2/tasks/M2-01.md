## 계약 (오케스트레이터 확정)

### 공개 API (전역 prefix `/api`, `@Public()` 표시는 M3 인증에서 — 지금은 가드 없음)

| Method · Path | 쿼리 · 파라미터 | 200 응답 | 그 밖의 응답 |
|---|---|---|---|
| `GET /api/posts` | `page`(정수 ≥1, 기본 1), `size`(1~50, 기본 9), `category`(slug), `tag`(slug), `featured`(boolean) | `PostListResponseDto` | 400 `VALIDATION_FAILED` |
| `GET /api/posts/{slug}` | `slug` | `PostDetailResponseDto` | 301(이전 slug, `Location` 헤더 — 문서에 응답만 기술), 404 `POST_NOT_FOUND` |
| `GET /api/categories` | — | `CategoryWithCountDto[]` (sortOrder 순) | — |
| `GET /api/tags` | — | `TagWithCountDto[]` | — |
| `GET /api/search` | `q`(문자열, 2자 이상 필수), `page`, `size` | `PostListResponseDto` | 400 `VALIDATION_FAILED` |

### 내부 API (전역 prefix **제외**, 경로 `/internal/posts/{slug}`)

| Method · Path | 헤더 | 200 응답 | 그 밖의 응답 |
|---|---|---|---|
| `GET /internal/posts/{slug}` | `X-Internal-Key`(필수, 문서에 header 파라미터로 표시) | `InternalPostResponseDto` 또는 `InternalPostRedirectDto` (OpenAPI `oneOf`) | 401 `UNAUTHORIZED`, 404 `POST_NOT_FOUND` |

- 전역 prefix 제외(`setGlobalPrefix(..., { exclude: [...] })`)는 이 작업에서 넣는다. OpenAPI 경로가 `/internal/posts/{slug}`로 나와야 하기 때문이다
- `/api/internal/*`로는 라우트가 없어야 한다(404)
- `InternalKeyGuard`·로그 마스킹은 M2-04에서 넣는다

### DTO

| DTO | 필드 (모두 required, `?`는 nullable) |
|---|---|
| `CategoryRefDto` | `name`, `slug` |
| `TagRefDto` | `name`, `slug` |
| `PostSummaryDto` | `slug`, `title`, `excerpt`, `coverImageUrl?`, `category?: CategoryRefDto`, `publishedAt`(ISO 8601), `readingMinutes`, `viewCount`, `likeCount` |
| `PostListResponseDto` | `items: PostSummaryDto[]`, `page`, `size`, `totalItems`, `totalPages` |
| `PostLinkDto` | `slug`, `title` |
| `PostDetailDto` | `PostSummaryDto`의 모든 필드 + `tags: TagRefDto[]`, `isFeatured`, `seoTitle?`, `seoDescription?`, `updatedAt` |
| `PostDetailResponseDto` (공개) | `post: PostDetailDto`, `prev?: PostLinkDto`, `next?: PostLinkDto`, `related: PostSummaryDto[]`(최대 3) |
| `InternalPostDto` | `PostDetailDto`의 모든 필드 + `contentMd`, `version` |
| `InternalPostResponseDto` | `post: InternalPostDto`, `prev?`, `next?`, `related` |
| `InternalPostRedirectDto` | `redirectTo`(새 slug) |
| `CategoryWithCountDto` | `name`, `slug`, `postCount`(발행 글 수) |
| `TagWithCountDto` | `name`, `slug`, `postCount` |

- 공개 API에 쓰는 어떤 스키마에도 `contentMd`·`version`이 없어야 한다(백엔드 §4.2). 이 규칙은 `$ref`·`allOf`를 따라가며 검사한다
- `PostDetailDto`가 공개 상세에도 쓰이므로, `contentMd`는 `InternalPostDto`에만 추가한다(상속 방향 주의)
- `prev`/`next`의 기준: `prev`는 더 오래된 글, `next`는 더 최근 글이다(`publishedAt` 기준). 구현 규칙은 M2-03에서 확정한다

### ① 계약 테스트 선작성 (test-engineer)

- 파일: `backend/test/blog-read-contract.e2e-spec.ts` (DB 없음, 닫힌 포트 더미 `DATABASE_URL`). 54건
  - 경로·파라미터 9건, 응답 코드·스키마 17건, DTO 필드·required·nullable 13건, 거부(공개 응답에 `contentMd`·`version` 없음, 재귀 검사 + 검사기 자체 확인) 6건, 501 6건 + `/api/internal/posts/x` 404 1건 등
- 실패 확인(구현 전): 54건 중 53건 실패, 1건 통과(`/api/internal/posts/x` 404는 라우트가 아직 없어서 통과, 구현 후에도 유지돼야 함). 실패 이유는 "문서에 GET 경로·components.schemas가 없다"와 "501 기대, 실제 404"이며 컴파일·환경 오류가 아니다. 기존 e2e 4개 스위트(40건)는 그대로 통과
- 구현이 지켜야 할 해석
  - nullable은 @nestjs/swagger 기본 출력대로 프로퍼티에 `nullable: true`. 객체 참조는 `nullable: true` + `allOf: [{ $ref }]`. `oneOf`+`type: 'null'`은 쓰지 않는다. `ApiProperty({ nullable: true })` 필요
  - 표의 모든 필드는 required(nullable 필드도 포함). `InternalPostDto`는 `PostDetailDto` 필드 + `contentMd`·`version`(둘 다 non-null, required). `allOf` 합성 또는 필드 복제 모두 허용. `contentMd`·`version`은 `InternalPostDto` 외 DTO에 없어야 한다
  - 배열 필드(`items`, `tags`, `related`)는 `items.$ref`, 200 응답의 categories·tags는 `type: array` + `items.$ref`
  - 쿼리: `page` default 1·minimum 1, `size` default 9·minimum 1·maximum 50, `featured` type boolean, `category`·`tag` type string, `q` required·type string·`minLength: 2`(`ApiProperty({ minLength: 2 })` 명시 필요), 선택 쿼리는 required 아님
  - 응답 코드: posts 200·400, posts/{slug} 200·301·404, categories·tags 200(400·404 없음), search 200·400, internal 200·401·404. 400·401·404 본문은 `$ref ErrorResponseDto`
  - 내부 200은 `oneOf`에 `InternalPostResponseDto`·`InternalPostRedirectDto` 두 `$ref`. `X-Internal-Key`는 `in: header`, `required: true`. 내부 경로는 `/internal/posts/{slug}`이며 `/api/internal*` 경로는 문서에 없다
  - 구현 전 핸들러는 501 `NOT_IMPLEMENTED`(공통 에러 형식, `path`는 쿼리 제외). `/internal/posts/some-slug`도 키 없이 501
