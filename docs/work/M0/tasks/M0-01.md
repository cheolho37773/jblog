- devops-engineer 참고
  - stub: `$tmp/stubbin/codex` (bash). `--output-last-message`/`-o <파일>`에 `STUB-REVIEW-RESULT`를 쓰고 종료. `STUB_MODE=hang`이면 결과 파일에 `partial`을 쓴 뒤 `sleep 60`을 백그라운드로 띄우고 `wait`. PID는 `$STUB_PID_DIR/{stub,child}.pid`, 호출 시 `$0`을 `$STUB_PID_DIR/used`에 기록. 구현은 codex에 `-o` 또는 `--output-last-message <파일>` 형태로 인자를 넘겨야 한다 (현재 형태 유지).
  - 테스트 PATH는 `<stub>:/usr/bin:/bin` 로 최소화한다. 스크립트가 쓰는 도구(git, date, sed, sort, grep, ls, python3, perl 등)는 `/usr/bin`·`/bin`에서만 찾을 수 있어야 한다. 환경변수는 PATH·HOME·STUB_*만 전달하고, `CODEX_BIN`은 해당 테스트만 설정한다.
  - 기대: shim 디렉터리 경로는 `.../cmux-cli-shims/bin`. 시간 초과 시 종료 코드 124, 결과 파일(부분 기록 포함) 삭제, stub과 자식 sleep 모두 종료(약 3초 내 확인). `--plan` 시 `docs/plan/feedback/`는 이미 존재한다고 가정(테스트가 만들어 둠). codex 없음은 종료 코드 1(메시지 문구는 검사하지 않음).

### devops-engineer (수정)
