# M0-05 FE-01 Next 기반 (Issue #13)

- 마일스톤: M0 · 이슈: #13 · 브랜치: `feat/M0-05-next-foundation` (`dev`에서 생성)
- 실행 방식: **서브에이전트 조합** — ① frontend-dev(프로젝트 골격) → ② devops-engineer(Vitest·Playwright·ESLint 플러그인) → ③ test-engineer(테스트 선작성, 실패 확인) → ④ frontend-dev(구현) → ⑤ test-engineer(독립 검증)
- 선택 이유: 새 완료 기준 테스트(환경변수 거부, 테마 전환, E2E 스모크)가 필요하고, 테스트 설정·테스트·구현의 소유자가 다르다(협업 §4.0, §4.3-a). M0-04와 같은 순서
- 난도·모델: 보통 → 모두 Sonnet
- 선행 준비: Node 24, `corepack pnpm install`, `core.hooksPath=.husky/_`(**바꾸지 않는다**)
- 계약 기준: 없음 (API 타입 생성·연동은 M0-07)
- 참조: 프론트엔드 §2(스택), §3(디렉터리 구조·계층 규칙, D26), §4 Revalidate Webhook 단락(Q5), §5.1(토큰 매핑 예시 — 이번엔 골격만), §5.1-a(폰트), §10(테스트), 개요 §2.1(버전 고정), §6·§6-b(환경변수·민감 정보), D25·D26, 스킬 `component-patterns`
- 쓰기 범위
  - frontend-dev: `frontend/**`(아래 제외), `pnpm-lock.yaml`
  - devops-engineer: `frontend/vitest.config.*`, `frontend/playwright.config.*`, `frontend/test/setup*.ts`, `frontend/.env.example`, `frontend/package.json`의 테스트 스크립트·테스트 devDependencies(Bash `pnpm --filter frontend add -D`·`node -e`로), 루트 `package.json`·`turbo.json`·`eslint.config.mjs`·`scripts/eslint/**`·`.gitignore`, `pnpm-lock.yaml`, `pnpm-workspace.yaml`
  - test-engineer: `frontend/src/**/*.spec.ts(x)`, `frontend/test/**`(`test/support/**`·`test/setup*.ts` 제외), `frontend/e2e/**`
- 오케스트레이터: 체크리스트 체크, 개요 §6 변수 목록 정합 확인
- 실행 명령: `pnpm --filter frontend build` · `pnpm --filter frontend test` · `pnpm test:e2e` · `pnpm lint` · `pnpm format:check` · `pnpm typecheck` · `pnpm test`
- 비밀값: 없음 (이번 작업의 환경변수는 `API_INTERNAL_URL`, `NEXT_PUBLIC_SITE_URL`뿐이고 둘 다 비밀값이 아니다. 테스트·E2E는 명백한 더미 URL을 쓰고 `frontend/.env*`를 읽지 않는다)
- 인계 대상: 각 단계 → 오케스트레이터 → 다음 단계 / 최종: 오케스트레이터(독립 확인·Codex 검수·push)
- 중간 보고 조건: 최신 안정 버전끼리 peer가 맞지 않음(React·Next·Tailwind·Vitest·TypeScript 6.0), 기획에 없는 환경변수가 필요함(G2), Next.js의 `revalidateTag` API가 기획 §4와 다름(기록 후 계속 — 기획 갱신은 G2로 따로), 가독성 ESLint 규칙과 React·Next 관용구가 충돌함, 에러 수정 3회 도달
- 하지 말 것: 디자인 토큰 전체·Atom 컴포넌트(FE-02, M1), Navbar·Footer(FE-03), API 타입 생성·연동(M0-07), `middleware.ts`(M3), Dockerfile(M0-08), shadcn/ui, Pretendard 로컬 폰트 파일 추가(FE-02, 라이선스 확인 필요), `backend/**`, **`frontend/.env*` 생성·읽기**(`.env.example`만 작성), `git config` 변경, `create-next-app`으로 생성(불필요한 ESLint·설정이 생긴다)
