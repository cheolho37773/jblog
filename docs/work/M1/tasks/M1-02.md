## 값 기준과 색 추출 (G1 결정 1)

- (확정) 값은 UI §3.3~§3.6 그대로
- (추정) 값(§3.3의 Dark `--text-body`·`--nav-text`·`--input-bg`·`--toggle-track`, Light `--surface-2`·`--footer-bg`·`--footer-link`, §3.4 그라디언트, §3.6 `--radius-full`, §10 #8 outline 보더)은 ③에서 **로컬 참고 스크린샷 `docs/ui_design/references/*.png`**(공개 안 함, 축소본)에서 색을 추출해 보정한다. 추출 방법·파일·좌표·결과를 인계 노트 표로 남기고, 추정값과 다르면 **값을 바꾸기 전에 보고**(오케스트레이터가 판단 — 스크린샷 압축·축소 보간 오차 고려)
- 참고 스크린샷이 없는 항목(Dark 글 상세 본문 등)은 추정값 유지, 인계 노트에 "확인 불가"
