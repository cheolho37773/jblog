## 동작 규약

| # | 항목 | 규약 |
|---|---|---|
| 1 | 빌드 스위치 (오케스트레이터 확정) | 개발 전용 페이지 파일은 확장자 `*.dev.tsx`(예: `src/app/dev/components/page.dev.tsx`)로 두고, `next.config.ts`가 **빌드 시점** 환경변수 `JBLOG_DEV_PAGES=1`일 때만 `pageExtensions`에 `dev.tsx`를 더한다. 운영 빌드(변수 없음)에는 **페이지 코드가 컴파일되지 않아** 자연히 404이고 번들에도 없다. 이 변수는 비밀값이 아니고 앱 런타임 설정이 아니므로 `env.schema`에 넣지 않는다(`next.config.ts`는 `process.env` 허용 위치). 개요 §6에 "빌드 전용 변수"로 기록(오케스트레이터) |
| 2 | Playwright 서버 2종 (devops) | `frontend/playwright.config.ts`에 프로젝트 2개: `prod`(지금처럼 운영 standalone 빌드 — 기존 스모크·토큰·`/dev/components` 404 테스트) / `components`(`JBLOG_DEV_PAGES=1`로 **별도 출력 폴더**에 빌드한 standalone 서버, 다른 포트 — `/dev/components` 캡처·동작 테스트). 두 빌드가 `.next`를 덮어쓰지 않게 `distDir` 분리 등(Next 문서 확인). 테스트 파일 구분은 폴더 또는 이름 규칙(예: `e2e/components/**`)으로. 루트 `pnpm test:e2e`가 둘 다 실행, CI `e2e` 잡도 둘 다 |
| 3 | 컴포넌트 (frontend) | `src/components/ui/`: `Badge`(variant `solid`·`soft`, size `md`·`lg`, `href` 있으면 링크), `Button`(variant `primary`·`outline`·`icon`·`pillSolid`·`pillOutline`, `asChild`로 링크 감싸기, `disabled`), `Avatar`(`src`·`alt`·size 28~80, 이미지 없으면 이니셜 대체), `Input`(label 연결, 오류 상태), `SearchInput`(`role="searchbox"`, 접근 가능한 이름, 검색 아이콘, placeholder 대비 토큰), `ThemeToggle`(UI §5.1 크기 48×28 트랙·노브·`--shadow-toggle`, 히트 영역 44px, 기존 동작 유지), `Icon`(lucide 이름 또는 simple-icons 슬러그, `currentColor`, 장식이면 `aria-hidden`). variant는 `class-variance-authority`, 클래스 병합은 `cn()`(`clsx`+`tailwind-merge`, `src/lib/cn.ts`). **토큰 유틸만** 쓰고 hex 금지 |
| 4 | `/dev/components` (frontend) | 섹션마다 컴포넌트의 모든 variant·크기·상태(기본·hover 표시용 고정 상태·focus·disabled)를 나열. 섹션 루트에 `data-testid="dev-<컴포넌트 이름 소문자>"`(예: `dev-badge`, `dev-button`). 페이지 상단에 테마 전환(기존 ThemeToggle). 타이포 유틸·그라디언트 텍스트(`text-gradient-*`, M1-02에서 넘긴 세로 그라디언트 확인용)·색 토큰 견본 섹션 `dev-tokens`도 둔다. `noindex` 메타 |
| 5 | 접근성 | UI §9: 포커스 링(키보드 포커스 시 `outline` 2px primary), 버튼은 `<button>`(링크면 `<a>`), 아이콘 버튼은 접근 가능한 이름 필수, 대비 토큰 사용, 터치 타겟 44px |
