### ① 테스트 선작성 (test-engineer)

- 파일: `frontend/src/lib/env.load-guard.spec.ts` (신규, 구현 미수정)
- `assertPublicKeysSafe` 단위 5건: 안전 목록 통과 / `NEXT_PUBLIC_API_KEY`·`JWT_SECRET`·`DATABASE_URL` 각각 그 이름을 담은 오류 / 여러 위험 이름 모두 포함·안전 이름 미포함
- 모듈 로드 경로 4건(`vi.resetModules` + `vi.doMock('./env.public-schema')`, 사례마다 초기화): 위험 키 스키마 → 로드 reject + 이름 포함 / 메시지에 안전 이름 미포함 / 안전 스키마 → 로드 성공, `PUBLIC_ENV_KEYS`가 스키마를 따름 / 앞선 위험 모킹이 다음 사례에 남지 않음
- 실패 확인: 전체 9건 실패, 기존 17건 통과. 사유는 의도한 것 — `assertPublicKeysSafe is not a function`, 모킹이 반영되지 않아 로드가 reject되지 않음(`promise resolved instead of rejecting`), 키 목록 불일치. 문법·설정 오류 없음
- 구현자 참고: 모킹 모듈은 `{ publicSchema }`만 내보낸다. `env.schema`는 `publicSchema`를 `./env.public-schema`에서 import해야 한다
