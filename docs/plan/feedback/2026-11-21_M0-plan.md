# M0-plan 검수 r1

## 종합 판정

수정 후 통과 — 작업 순서와 주요 완료 기준은 정리되어 있으나, api-types 작업의 소유권·계약 분류, 검수 스크립트의 독립 테스트, Playwright 기반 작업 배정을 보완해야 한다.

## 지적 사항

### 1. [중간] M0-07의 참여 역할과 실행 방식으로는 예정된 산출물을 처리할 수 없음

- 위치: `docs/work/M0/plan.md:24`
- 근거: `docs/plan/05_collaboration_architecture.md` §5.2는 web 코드·패키지를 Frontend 소유로 지정하고, `packages/api-types/**` 변경을 `contract/` 브랜치에서만 허용한다. §5.3은 OpenAPI 계약 책임자를 Backend로 지정한다. 그러나 M0-07은 DevOps 단독 실행으로 배정하면서 web import 연동과 DTO 변경에 따른 타입 반영까지 완료 기준에 포함한다.
- 영향: web 의존성·import를 추가하거나 DTO 계약을 변경하면 승인된 역할 범위를 벗어난다. 일반 작업 브랜치에서 생성 타입을 추가하면 예정된 `ownership-check`의 계약 브랜치 제한에도 걸린다.
- 권고: 파이프라인 설정과 계약·web 연동의 범위를 구분하고, 필요한 Backend·Frontend 역할과 계약 브랜치 사용을 명시한다. DTO 변경 검증이 임시 시험이라면 그 범위도 명확히 적는다.

### 2. [중간] M0-01 버그 수정에 재현 테스트 담당이 빠짐

- 위치: `docs/work/M0/plan.md:18`
- 근거: `docs/plan/05_collaboration_architecture.md` §4.0은 버그 수정에 Test Agent의 재현 테스트 선작성을 요구하고, §4.2도 단일 실행의 버그 수정에서 재현 테스트를 요구한다. M0-01은 회차 계산 버그와 실행 멈춤을 수정하면서 DevOps 단독 실행으로만 배정되어 있다.
- 영향: 날짜 변경·작업 ID 경계·시간 초과 처리에 관한 완료 기준이 구현자 자체 확인에만 의존하여, 요구된 독립 검증과 재발 방지 테스트가 누락된다.
- 권고: `단일 실행 + 재발 방지 테스트`로 변경하고, Test Agent가 회차 계산과 시간 초과의 재현 테스트를 먼저 작성하도록 배정한다.

### 3. [중간] M0 필수 항목인 Playwright 공통 설정이 작업 목록에서 누락됨

- 위치: `docs/work/M0/plan.md:25`
- 근거: `docs/work/00_master_checklist.md`의 M0는 Jest·Vitest·Playwright 공통 설정과 `pnpm test:*` 명령을 요구한다. `docs/plan/05_collaboration_architecture.md` §4.3-a도 이를 DevOps 책임으로 지정한다. 계획서는 M0-04에 Jest, M0-05에 Vitest를 배정하지만 Playwright 설정·실행 명령·서버 기동 기반은 어느 작업에도 배정하지 않는다.
- 영향: 계획된 9개 작업을 모두 수행해도 M0 체크리스트의 테스트 환경 항목이 남는다. M1 디자인 검수에서 필요한 Playwright 기반도 준비되지 않는다.
- 권고: M0-05 또는 M0-08에 Playwright 공통 설정, 실행 명령, `webServer` 기동 기반을 배정하고 최소 실행 확인을 완료 기준에 추가한다.
