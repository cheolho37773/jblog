# M1-plan 검수 r1

## 종합 판정

수정 후 통과 — 미확정 디자인 값의 변경 영향과 시각 검수 환경 담당이 계획에서 빠져 있다. 계약 작업에 포함된 환경변수 검사 개선도 분리해야 한다.

## 지적 사항

### 1. [중간] Q4 확정 이후 수정 범위를 토큰으로만 한정함

- 위치: `docs/work/M1/plan.md:32`, `docs/work/M1/plan.md:73`
- 근거: `docs/ui_design/ui_design_spec.md` §10의 미확정 항목에는 프로젝트 카드 정보바 패딩, CTA 크기·보더 두께, PageInfo/Breadcrumb 상세가 포함된다. 이 값들이 모두 M1-02 토큰으로 관리된다는 정의는 없으며, PageInfo 상세는 컴포넌트 구성에도 영향을 줄 수 있다.
- 영향: M1-03~05 이후 Q4가 확정되면 컴포넌트와 검증 결과까지 바뀔 수 있는데, 계획은 토큰 값 교체만으로 처리한다고 안내한다. 기존 기준 이미지와 디자인 승인 결과가 유효하지 않게 될 수 있다.
- 권고: 항목별 영향 대상을 명시하고, Q4 확정 시 계약 변경 여부 판단 → 관련 컴포넌트 수정 → 동작·디자인 재검수 → 기준 이미지 재승인 순서를 추가한다.

### 2. [중간] 개발 전용 페이지의 CI 시각 검수에 필요한 환경 변경 담당 누락

- 위치: `docs/work/M1/plan.md:22`, `docs/work/M1/plan.md:36`
- 근거: 계획은 운영 빌드에서 `/dev/components`를 404로 만들면서 해당 페이지의 시각 회귀를 기존 `e2e` 잡에 포함한다. 현재 `frontend/playwright.config.ts`는 `pnpm build` 후 운영 형태의 standalone 서버만 실행한다. 테스트 공통 설정·실행 명령·CI 변경은 `docs/plan/05_collaboration_architecture.md` §4.3-a·§5.2에서 DevOps 소유지만, 작업 목록에는 DevOps 참여가 없다.
- 영향: 기존 실행 방식으로는 컴포넌트 화면 대신 404를 캡처하게 된다. 이를 해결하려면 현재 배정에 없는 역할과 설정 변경이 필요하다.
- 권고: M1-03 또는 선행 환경 작업에 DevOps를 배정한다. 컴포넌트 캡처용 서버와 운영 빌드 404 검증용 서버의 실행 방식, CI 연결, 쓰기 범위를 명시한다.

### 3. [중간] 토큰 계약 PR에 별도 환경변수 검사 개선을 포함함

- 위치: `docs/work/M1/plan.md:19`
- 근거: `docs/plan/05_collaboration_architecture.md` §5.3-a의 계약 확정 단계는 토큰 등 계약만 포함하고 동작 구현은 제외한다. 반면 Issue #24의 해소 조건은 `docs/work/M0/report.md` §7에 공개 키 주입이 가능하도록 검사 함수를 분리하고 실패 동작을 테스트하는 것으로 정의되어 있다.
- 영향: 디자인 토큰 계약 확정에 관계없는 환경변수 검사 코드 변경이 같은 PR에 섞여 계약 작업의 검수 범위와 완료 조건이 확대된다.
- 권고: Issue #24를 별도 수정 작업으로 분리하고 Test·Frontend 역할과 완료 기준을 배정한다. M1-02는 토큰 계약과 그 검증에 집중시킨다.

## 확인한 범위

- 변경 파일: `docs/work/M1/plan.md` 전체.
- 대조 문서: 개요 §6-b·§7·§8, 프론트엔드 §2·§3·§5, UI 디자인 §3~§5·§8~§12, 협업 아키텍처 §4·§5·§6.4-a·§7·§10, 전체 체크리스트 M1, M0 report의 후속 항목.
- 환경 확인: `frontend/playwright.config.ts`, `.github/workflows/ci.yml`, 환경변수 검사 관련 코드·테스트와 M0-05 지시서.
- 읽기 전용 명령: 지정 구간의 `git diff`, `git diff --name-only`, `git diff --check`, `git status --short`, `git rev-parse HEAD`, `rg`, `cat`, `sed`, `nl`.
- HEAD는 지정 SHA와 일치한다. `git diff --check`에서 공백 오류는 없었다. 기획 문서 변경 검수이므로 빌드·테스트는 실행하지 않았다.
- 미추적 기존 피드백 파일은 검수 근거에서 제외했다. 파일을 수정하지 않았다.
